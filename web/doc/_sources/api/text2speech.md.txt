# Text To Speech
文字转语音

```{admonition} POST &nbsp; /v1/audio/speech

Header:  
- Content-Type: application/json  
- Authorization: Bearer <font class="stress">$API_KEY</font>  

参数：
- <font class="haha">model</font>: string, 模型名称；
- <font class="haha">input</font>: string, 文本内容；
- <font class="haha">voice</font>: string, 语音名称；
```


::::{tab-set}

:::{tab-item} `Curl`
```shell
curl -X POST \
    http://proxy.aiapps.autel.com/v1/audio/speech \
    -H "Content-Type: application/json"  \
    -H "Authorization $API_KEY" \
    -d '{
        "model": "tts-1",
        "input": "Hello, how are you?",
        "voice": "alloy"
    }' \
    --output speech.mp3
```
:::

:::{tab-item} `Python`
```python
import json
import requests

url = "http://proxy.aiapps.autel.com/v1/audio/speech"
api_key = "你的令牌"    # 替换为你的令牌
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {api_key}"
}
payload = {
    "model": "tts-1", 
    "input": "Hello, how are you?", 
    "voice": "alloy"
}
r = requests.post(url, json=payload, headers=headers)
if not r.ok:
    raise requests.HTTPError(f"Failed to request embeddings, {r.status_code}: {r.text}")

with open("speech.mp3", "wb") as f:
    f.write(r.content)
```
:::
