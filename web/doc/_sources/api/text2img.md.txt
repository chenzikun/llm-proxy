# Text To Image
文生图

```{admonition} POST &nbsp; /images/generations

Header:
- Content-Type: application/json
- Authorization: Bearer <font class="stress">$API_KEY</font>  

参数：
- <font class="haha">model</font>: string, 模型名称；
- <font class="haha">prompt</font>: string, 输入文本；
- <font class="haha">n</font>: int, 生成图片数量，默认为1；
- <font class="haha">size</font>: string, 图片尺寸，默认`1024x1024`；
    > - 对于`dall-e-2`模型，支持的尺寸有`256x256`，`512x512`，`1024x1024`；  
    > - 对于`dall-e-3`模型，支持的尺寸有`1024x1024`，`1792x1024`，`1024x1792`；  
- <font class="haha">quality</font>: string, 图片质量，默认`standard`；
    > - 仅`dall-e-3`模型支持`quality`参数，可选值有：`standard`，`hd`；
    > - `hd`可创建具有更精细细节和更高一致性的图像；
- <font class="haha">style</font>: string, 图片风格，默认`vivid`；
    > - 仅`dall-e-3`模型支持`style`参数，可选值有：`vivid`，`natural`；  
    > - `vivid(生动)`会使模型倾向于生成超现实和戏剧性的图像；  
    > - `natural(自然)`会使模型产生更自然，看起来不那么超现实的图像；  
- <font class="haha">response_format</font>：string, 返回格式，默认`url`；
    > - 可选值有：`url`，`b64_json`；
    > - `url`返回图片的URL，该URL在60分钟内有效；
    > - `b64_json`返回图片的base64编码；
```


::::{tab-set}

:::{tab-item} `Curl`
```shell
curl -X POST \
    http://proxy.aiapps.autel.com/images/generations \
    -H 'Content-Type: application/json' \
    -H "Authorization: Bearer $API
    -d '{
        "model": "text2img-ada-002",
        "prompt": "a beautiful sunset over the ocean",
    }'
```

:::

:::{tab-item} `Python`
```python
import json
import requests

url = "http://proxy.aiapps.autel.com/images/generations"
api_key = "你的令牌"    # 替换为你的令牌
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {api_key}"
}

payload = {
    "model": "text2img-ada-002",
    "prompt": "a beautiful sunset over the ocean",
    "response_format": "b64_json",
}
r = requests.post(url, json=payload, headers=headers)
if not r.ok:
    raise requests.HTTPError(f"Failed to request embeddings, {r.status_code}: {r.text}")
print(r.json())
content = r.json()["data"][0]["b64_json"]
img_bytes = base64.b64decode(content)
with open("image.jpg", "wb") as f:
    f.write(img_bytes)
```
