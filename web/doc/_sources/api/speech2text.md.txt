# Speech To Text
语音转文字
```{admonition} POST &nbsp; /v1/audio/transcriptions

Header:  
- Content-Type: multipart/form-data
- Authorization: Bearer <font class="stress">$API_KEY</font>  

参数：
- <font class="haha">model</font>: string, 模型名称；
- <font class="haha">file</font>: file, 音频文件；
```


::::{tab-set}

:::{tab-item} `Curl`
```shell
curl -X POST \
    http://proxy.aiapps.autel.com/v1/audio/transcriptions \
    -H "Content-Type: multipart/form-data"  \
    -H "Authorization: Bearer $API_KEY" \
    -F model="whisper-1" \
    -F file="@/path/to/file/audio.mp3"
```
:::

:::{tab-item} `Python`
