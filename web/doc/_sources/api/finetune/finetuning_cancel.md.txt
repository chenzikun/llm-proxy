# 取消微调任务

```{admonition} POST &nbsp; /v1/fine_tuning/jobs/{job_id}/cancel

Header:  
- Authorization: Bearer <font class="stress">$API_KEY</font>  
```


::::{tab-set}

:::{tab-item} `Curl`
```shell
curl -X POST \
    http://proxy.aiapps.autel.com/v1/fine_tuning/jobs/{job_id}/cancel \
    -H "Authorization: Bearer $API_KEY"
```
:::
