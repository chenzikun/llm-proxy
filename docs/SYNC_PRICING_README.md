# 模型价格同步脚本使用说明

## 📚 脚本概览

本项目提供了三个脚本来帮助您同步不同环境间的模型价格：

| 脚本 | 功能 | 适用场景 |
|------|------|---------|
| `test_environments.py` | 测试所有环境的连接性 | 在同步前先测试环境 |
| `sync_model_pricing.py` | 基础版同步脚本 | 快速一键同步 |
| `sync_model_pricing_advanced.py` | 增强版同步脚本 | 需要精细控制的场景 |

## 功能说明

这些脚本用于将美国生产环境（eneprodus）的模型价格同步到其他所有环境。

**同步规则**:
- ✅ 只同步**同名模型**的价格
- ✅ 只同步 `model_ratio`（输入价格倍率）和 `completion_ratio`（输出价格倍率）
- ✅ 如果目标环境没有某个模型，则跳过该模型
- ✅ 如果价格已经一致，则跳过更新
- ❌ 不会创建新模型
- ❌ 不会删除模型
- ❌ 不会修改模型的其他属性（如状态、渠道类型等）

## 🚀 快速开始

推荐的使用流程：

### 第一步：测试环境连接

在实际同步前，先测试所有环境的连接性：

```bash
python test_environments.py
```

这个脚本会：
- 并发测试所有环境的网络连接
- 验证登录认证是否成功
- 检查API访问权限
- 显示每个环境的模型数量
- 给出总体评估和建议

### 第二步：干运行查看差异（推荐）

使用干运行模式查看有哪些模型价格存在差异，但不实际更新：

```bash
# 查看所有环境的价格差异
python sync_model_pricing_advanced.py --dry-run

# 导出差异报告到CSV文件
python sync_model_pricing_advanced.py --dry-run --report pricing_diff.csv
```

### 第三步：执行实际同步

确认差异无误后，执行实际的价格同步：

```bash
# 方式一：使用基础版脚本（快速一键同步）
python sync_model_pricing.py

# 方式二：使用增强版脚本
python sync_model_pricing_advanced.py
```

### 2. 基础版同步脚本 (sync_model_pricing.py)

**功能**：简单直接的一键同步，无需参数

### 3. 增强版同步脚本 (sync_model_pricing_advanced.py)

**功能**：功能丰富的同步脚本，支持多种参数和选项

**适用场景**：
- 需要先查看差异再决定是否更新
- 只想同步特定环境或特定模型
- 需要导出差异报告

**命令行参数**：

| 参数 | 说明 | 示例 |
|------|------|------|
| `--dry-run` | 干运行模式，只分析差异不实际更新 | `--dry-run` |
| `--env` | 只同步到指定环境（逗号分隔） | `--env dev,enetest` |
| `--models` | 只同步特定模型（逗号分隔） | `--models gpt-4o,gpt-4o-mini` |
| `--report` | 导出差异报告到CSV文件 | `--report diff.csv` |
| `--list-envs` | 列出所有可用环境 | `--list-envs` |

**使用示例**：

```bash
# 1. 列出所有可用环境
python sync_model_pricing_advanced.py --list-envs

# 2. 干运行模式（查看差异，不实际更新）
python sync_model_pricing_advanced.py --dry-run

# 3. 导出差异报告到CSV
python sync_model_pricing_advanced.py --dry-run --report pricing_diff.csv

# 4. 只同步到开发和测试环境
python sync_model_pricing_advanced.py --env dev,enetest

# 5. 只同步特定模型
python sync_model_pricing_advanced.py --models gpt-4o,gpt-4o-mini,claude-3

# 6. 组合使用：只在开发环境测试特定模型
python sync_model_pricing_advanced.py --env dev --models gpt-4o --dry-run

# 7. 查看帮助信息
python sync_model_pricing_advanced.py --help
```

## 工作流程

1. **登录源环境**
   - 使用管理员账号登录美国生产环境

2. **获取源环境模型价格**
   - 获取所有模型的价格信息
   - 构建模型名称到价格的映射表

3. **遍历目标环境**
   - 对每个目标环境：
     - 登录该环境
     - 获取该环境的所有模型
     - 找到与源环境同名的模型
     - 比较价格是否一致
     - 如果不一致则更新

4. **生成同步报告**
   - 显示每个环境的同步结果
   - 显示总体统计信息

## 安全说明

⚠️ **重要提示**:
- 这个脚本会修改生产环境的数据
- 建议先在测试环境验证
- 脚本会跳过价格已经一致的模型，避免不必要的更新
- 所有操作都有详细的日志记录

## 故障排查

### 登录失败

如果某个环境登录失败，可能的原因：
1. 网络连接问题
2. 账号密码错误
3. 环境不可访问

脚本会跳过登录失败的环境，继续处理其他环境。

### SSL证书问题

如果遇到SSL证书验证问题，脚本已经配置了 `verify=False` 来忽略证书验证。

### API权限问题

确保使用的账号具有管理员权限（Admin），否则无法访问模型管理API。

## 📊 差异报告说明

使用 `--report` 参数导出的CSV报告包含以下字段：

| 字段 | 说明 |
|------|------|
| 环境 | 目标环境名称 |
| 模型名称 | 模型的名称 |
| 源环境输入价格 | 源环境的model_ratio值 |
| 目标环境输入价格 | 目标环境当前的model_ratio值 |

| 源环境输出价格 | 源环境的completion_ratio值 |
| 目标环境输出价格 | 目标环境当前的completion_ratio值 |
| 输出价格差异 | 两者的差值（正数表示目标需要提高） |
| 状态 | 更新状态（待更新/更新成功/更新失败） |

## ⚠️ 注意事项

1. **权限要求**
   - 必须使用管理员账号（root）
   - 账号必须在所有环境都可用
   - 确保账号有访问模型管理API的权限

2. **网络要求**
   - 需要能访问所有环境的域名
   - 建议在公司内网运行
   - 如遇证书问题，脚本已配置跳过SSL验证

3. **安全建议**
   - 先在测试环境验证
   - 使用干运行模式确认差异
   - 导出报告供审核
   - 生产环境更新前做好备份

4. **性能说明**
   - 环境测试脚本使用并发，速度较快（约5-10秒）
   - 同步脚本串行处理，时间较长（取决于环境数和模型数）
   - 每个环境约需30-60秒

5. **幂等性**
   - 脚本可以重复运行
   - 已同步的模型会被自动跳过
   - 不会造成重复更新

## 🔍 故障排查

### 问题1：某个环境连接超时

**可能原因**：
- 网络不可达
- 防火墙阻止
- 环境暂时不可用

**解决方案**：
- 先运行 `test_environments.py` 诊断
- 检查网络连接
- 使用 `--env` 参数跳过该环境

### 问题2：登录失败

**可能原因**：
- 用户名密码错误
- 该环境的账号配置不同

**解决方案**：
- 检查脚本中的 USERNAME 和 PASSWORD
- 尝试手动登录该环境的Web界面验证
- 确认账号在该环境有管理员权限

### 问题3：API访问被拒绝

**可能原因**：
- 账号没有管理员权限
- API路径变更

**解决方案**：
- 检查账号权限
- 查看该环境的后台日志
- 联系系统管理员

### 问题4：模型没有被更新

**可能原因**：
- 价格已经一致（会被跳过）
- 目标环境没有这个模型
- 更新API失败

**解决方案**：
- 使用 `--dry-run` 查看是否会更新
- 查看脚本输出的详细日志
- 检查目标环境是否存在该模型
